# cloudz13.github.io

## Page index

`inde.html` lists every HTML page in the repo root. Whenever you add, rename, or remove a root `.html` page, update `inde.html` in the same change: add/edit/remove its link card, using the page's `<title>` as the label and the filename as the subtitle. Never list `inde.html` itself. Pages are grouped into category sections (Company, Oracle DR & Security, Cloud Cost, Finance, Personal & Events); put new pages in the best-fit category (add a new one if needed), give each card a one-line description, and keep the count badge in each section heading correct.
