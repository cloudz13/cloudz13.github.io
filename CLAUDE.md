# cloudz13.github.io

## Page index

`inde.html` is the directory of every HTML page in the repo root. Whenever you add, rename, or remove a root `.html` page, update the `PAGES` array in `inde.html` in the same change: `{file, title, desc, cat}` — `title` from the page's `<title>`, `desc` a one-line description, `cat` the best-fit category (current: Company, Oracle DR & Security, Cloud Cost, Finance, Personal & Events; add a new one if none fits — categories and counts are derived automatically). Never list `inde.html` itself.
