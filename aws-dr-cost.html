Passive DR in AWS Mumbai: cost calculator

Prepared by CloudZ13 (DB services) · ← DR scenarios

This page estimates the monthly cost of a passive ("pilot light") DR site in AWS Asia Pacific (Mumbai), ap-south-1. The site would replace the Oman DR site. Only the Oracle DB server runs all the time to receive changes. The two Tomcat servers stay stopped, and the load balancer sits idle until a failover. Prices are AWS list prices in USD.

What runs, and what you pay for

In passive mode AWS charges for the running DB server, all disks (EBS volumes), the idle load balancer and the VPN link. Stopped servers have no compute charge.

Always on

DB server (EC2 compute), DB disk, VPN connection, public IPs, backups in S3.

Stopped

Tomcat servers: no compute charge, but their disks (or snapshots) are billed every month.

Only on failover

Tomcat compute, load balancer traffic (LCUs) and data sent out to users.

Notes and assumptions

Sizing

  • "4 core, 32 GB". On AWS, 4 vCPU (e.g. r6i.xlarge) is 2 physical cores with hyper-threading. For 4 physical cores and 32 GB, use an 8 vCPU type such as m6i.2xlarge or m6a.2xlarge. Both are in the list.
  • Tomcat disk. The default is 2 TB total (1 TB on each of 2 servers). Change "Disk per server" if you meant 2 TB each.
  • Tomcat disks are the biggest lever. A 1 TB gp3 volume costs about $91/month even when the server is stopped. Keeping only snapshots costs $0.05 per GB actually used. The trade-off is an extra restore step (a few minutes) at failover.
  • A month is 730 hours. EBS gp3 includes 3,000 IOPS and 125 MB/s at no extra cost.

Not included / check separately

  • Oracle licence. *Under Oracle's cloud licensing policy, SE2 on AWS counts an instance with up to 4 vCPU as 1 socket, and each further 4 vCPU as another socket (SE2 is capped at 8 vCPU). A standby that is kept in sync usually needs to be licensed too. Confirm with your Oracle contract.
  • GST (18%) on AWS invoices in India, AWS Support plan, and Direct Connect (if you use it instead of VPN).
  • Data transfer is billed per GB at $0.1093 for the first 10 TB. The 100 GB/month AWS free tier is ignored.
  • "While running on DR" assumes the Tomcats run 24×7 on-demand, the load balancer carries traffic, and snapshots are restored to gp3 volumes.
