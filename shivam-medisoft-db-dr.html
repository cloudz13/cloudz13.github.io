Oracle 21c DR: Ransomware Defense

Shivam Medisoft · Primary Hyderabad → Standby Mumbai → MIS snapshot

Critical

Backups can be encrypted

  • Keep one copy offline or immutable
  • Keep backup storage off the DB hosts
  • Test restores every quarter
Critical

Infection copied to DR

  • Apply logs on the standby 2–4 hours late
  • Turn on Flashback and keep restore points
Critical

Unpatched software

  • Patch Oracle (quarterly RUs), the OS and the VPN on a schedule
  • Upgrade to 23ai before 2027
High

VPN & app server entry

  • Require MFA on the VPN; route users through a jump host only
  • Run EDR on the app server; give the app account no DBA rights
High

Spread between servers

  • Use host firewalls: port 1521 from the app server only
  • Isolate MIS from the standby and backups
  • Use unique, vaulted admin passwords
High

Slow detection & recovery

  • Run EDR on DB hosts and alert on mass file changes
  • Keep an offline runbook; drill it twice a year

Action plan

Week 1–2Immutable backup, VPN MFA, host firewalls

Month 1Delayed apply + Flashback, EDR, jump host

Quarter 1Restore drill, full patching

2026–27Upgrade to 23ai
